> 使用者应认识到，这些资料**仅供参考**，其准确性和完整性不作任何保证，课程考核要求请务必以授课教师的最新通知为准。如果您是任何资料的版权方并认为其收录不当，请通过 [Issues](https://github.com/AquaSkyballad/UPC-Archive/issues) 页面联系我们，我们将在收到请求后立即核实并下架相关内容。

## 简介

本仓库旨在汇集中国石油大学（华东）各专业的课程学习资料，重点收录**期末复习资料**，包括但不限于：

- 📖 **课程课件**与**部分习题答案**
- 📄 **历年期末试卷**与**参考答案**

我们希望借此帮助在校同学系统复习、高效备考、在此也预祝每一个油砖学子考试顺利。

## 资料分类

仓库结构大致按**开课学院-课程-课程资料**分类，主要涵盖以下学科（持续更新中）：

| 开课学院 | 课程 |
|------|----------|
| 理学院 | 数学分析(2-1)、高等数学(2-1) |
| 化学化工学院 | 大学化学 |

> 💡 提示：具体课程资料请查看相应文件夹内的 `README.md` 了解详情。

## 使用建议

1. **快速检索**：使用 GitHub 的搜索功能（按 `s` 键）直接查找课程名称或代码
2. **按需下载**：可单独下载某个文件或通过 `git clone` 命令克隆整个仓库
3. **高效复习**：结合课程大纲和历年真题，有针对性地使用资料中的重点总结
4. **贡献改进**：发现错误或拥有更优质资料？欢迎提交 Pull Request 共同完善[5](@ref)

## 贡献指南

我们热烈欢迎并感谢任何形式的贡献！您可以通过以下方式参与[贡献指南](CONTRIBUTING.md)：

### 🐛 提交问题

若发现资料缺失、错误或对内容有疑问，请通过 [Issues](https://github.com/AquaSkyballad/UPC-Archive/issues) 页面反馈。

### 📥 提交资料（Pull Request）

1. **Fork 本仓库**
2. **按分类添加资料**：请将资料放入对应的学院-专业-课程文件夹中
3. **规范命名**：建议使用 `课程名称_资料类型_日期` 的格式（如 `数据结构_期末试卷_2023秋.pdf`）
4. **提交PR**：填写清晰的描述说明您添加的内容

### 📌 贡献要求

- 请确保资料内容**准确、清晰、完整**
- 尽量提供可编辑格式（如.md、.tex）或通用格式（如.pdf、.doc）
- 不提交受版权严格保护的资料（如正式出版物的完整扫描件）
